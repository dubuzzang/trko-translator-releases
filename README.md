# 튀르키예어 번역기 — 배포 파일

튀르키예어 PDF · 영상을 한국어 워드 · 대본으로 옮기는 프로그램의 **배포 전용** 저장소입니다 (소스 코드는 여기 없습니다).

## 받기

[최신 릴리스](../../releases/latest)에서 `TrKoTranslator-v<버전>-win-x64.zip` 을 받아 압축을 풀고 **튀르키예어번역기.exe** 를 실행하세요.

## 업데이트

프로그램 창 아래 **[업데이트 확인]** 을 누르면 이 저장소의 최신 릴리스를 받아 바꿉니다. GitHub 로그인은 필요 없습니다.
받은 파일은 크기와 검증값(SHA-256)을 대조한 뒤에만 바꿉니다.
